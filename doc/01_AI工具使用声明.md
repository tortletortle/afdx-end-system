# AI 工具使用声明

（赛题要求：技术文档须单独披露工具、场景与大致占比。本页随源码包提交，PPT 汇报请同步放一页。）

## 1. 工具名称与版本

- Cursor 编辑器内的 AI 编程助手（对话代理；具体底层模型以当时会话为准）
- 用途限于方案梳理、RTL/TB 修改建议、文档口径对齐、打包脚本、汇报材料起草

## 2. 使用场景

| 场景 | 是否使用 AI | 说明 |
|---|---|---|
| 文献与赛题条款梳理 | 是 | 对照已有本地文献目录与组委会答疑，不替代原文 |
| RTL / testbench 编写与缺陷修复 | 是 | 管理面上线 FSM、T24/T25 等；以 Questa 日志为验收 |
| 黄金模型 / 向量脚本 | 部分 | 既有 Python 模型为人机协作历史产物 |
| 仿真回归执行 | 否（工具链） | Questa / eLinx / Quartus 由本机运行 |
| 综合、Fit、STA 结论 | 否 | 以工具原始日志为准；未完成项不由 AI 判定达标 |
| 本文档与汇报口径 | 是 | 润色与结构整理 |

## 3. 生成内容占比（估计，供评委知情）

- 文字（设计书/报告/本包说明）：约 30%～50% 经 AI 起草或改写，结论数字均要求回溯到 CSV/日志
- RTL 代码：核心数据通路为项目既有实现；2026-10 管理面上线及相关 TB 有 AI 辅助修改，以仿真 PASS 为准
- 电路/FPGA 网表与时序：0% AI 生成

## 4. 责任

AI 输出不作为签核。功能以 `evidence/rtl_regress_70/` 原始 console 为准；未测项见 `00_先读_提交范围与汇报口径.md`。
