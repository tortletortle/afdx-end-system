AFDX 帧结构查看器

本地确定性构帧模型：演示长度、字段、IP/UDP 校验和与 FCS。
非 RTL 输出
8 B（项目主机口径）1471 B
帧字节预览 · 载荷模式 byte[i] = i mod 256
长度口径：IP Total Length = 28 + L；UDP Length = 8 + L；Pad 和 SN 均不计入 IP/UDP 长度和 UDP 校验和。SN 在 FCS 前 1 字节，FCS 低字节先发。此演示不含前导码/SFD，字段色块不按长度等比例绘制。


帧边界
64–1518 B
从 DMAC 到 FCS 计算帧长。载荷小于 17 B 时填充；最大 UDP 载荷为 1471 B。IPv4 固定 20 B 头，不包含 IP 分片/重组能力声明。
接口语义
同一 RTL，两种节拍
模式 0 用 ready 包络整帧、valid 选通字节；模式 1 连续字节约 1 Gbps。不能把该 ready 当成普通逐字节反压信号。
规范需对齐
SN 首帧不是一句“复位 0”
常规序列 1…255 循环。当前 RTL 把存储初值 0 映射为发送 1；与仓库规范摘录的发送端复位首发 0 有差异，需继续核对与测试。

TFTP 锁步传输
本地取走响应，与远端确认数据，是两种事件。
DATA(k)→ACK(k)→DATA(k+1)
完整 512 B 整数倍镜像需要零字节末块；重复 ACK 不立即重传，超时重发原块，外来 TID 不污染原会话。

07 / RISKS & DELIVERY
风险与交付
不把“实现了”说成“证明了”，也不把过期问题当成当前缺陷。




下一阶段的优先顺序
先稳定行为，再证明指标，最后形成可复验交付。
01
补边界用例，修真实行为
把 RM 和调度器反例迁入正规回归；先失败取证，再做最小必要修复，同时保护正常回绕、BAG 和复位语义。
02
冻结管理面与接口合同
区分 TFTP 子集和完整 615A、观测窗响应和网络回包；明确 GMII 节拍、RTC 测量对象以及可承诺指标。
03
建立一次干净的完整回归
独立 run-id、work library、向量/源码快照和失败原件；子集补跑不冒充全量，负例必须因目标原因失败。
04
完成当前版覆盖、波形与时序证据
优先修复热点而非无测量依据地大改配置表；保持 8 ns 内部目标，重新执行同器件多角 post-fit。
