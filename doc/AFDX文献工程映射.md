更新：2026-09-28（新增 §5：L096–L158 到 REQ 的映射）

> 本文件是文献来源的辅助索引；当前实现状态、需求状态和下一步以 [AFDX项目应用追踪](AFDX项目应用追踪.md) 为准。这里不重复维护一套独立的 RTL 完成状态。

## 1. 使用方式

- `L*`：文献目录中的来源 ID；
- `REQ-*`：项目应用追踪中的需求/工程问题；
- `T*`：仿真测试 ID；
- 文献“支持”不等于当前实现；当前实现必须由 RTL/TB/日志/综合/STA 证据证明；
- 普通千兆以太网、RGMII、PHY 和 CDC 资料只支撑接口/实现方法，不能支撑 AFDX 协议合规。

## 3. 按项目阶段查文献

### 3.1 编码阶段

- TX 帧/BAG：L001、L008、L041、L063、L064；
- RX IC/RM/SkewMax：L007、L077-L080、RM_AFDX_MengLi 论文、UPPAAL 帧管理论文；
- 端口/块所有权：L010、L016、L044、L047；
- GMII/接口：L085、L088、L089、TI PHY 手册。

### 3.2 验证阶段

- 端系统自动化符合性：L071、L087；
- 传输特性和测试指标：L068、L070、L081、L084；
- 故障/形式化：L079、UPPAAL 帧管理论文、`CDC_TMR_sync.pdf`；
- 管理面：L074、RFC1157、RFC3416、RFC3417、ASN.1/BER 指南。

### 3.3 答辩/交付阶段

应引用三层证据并明确层级：

1. 赛方边界：`doc_组委会问答.md`；
2. 文献/公开协议参考：`L*` 和 RFC；
3. 本项目实际结果：`sim/tests.manifest`、Questa 日志、CSV、波形、综合/STA 报告。

不得用第 2 层替代第 3 层。

## 4. 复查清单

- 需要确认标准条文：ARINC 664 Part 7、ARINC 615A；公开论文只能作替代参考；
- 需要确认项目子集：SNMP、615A、RTC；
- 需要确认当前证据：完整 T08/T22、长时 T17/T18、顶层综合、CDC/STA；
- 需要确认 RM 语义：多帧迟到副本、序列历史窗口、network babbling；
- 需要确认接口口径：GMII 为赛方主接口，RGMII/PHY 资料不改变赛题边界。
