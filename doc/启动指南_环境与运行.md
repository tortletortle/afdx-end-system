# 启动指南：环境与运行

## 0. 一句话

AFDX 端系统 FPGA 工程。跑功能回归只需仿真器 + Python。综合和形式验证可选。

本页不是最终交卷包，也不代替 `doc/验收尺子.md`。

## 1. 必需环境

| 工具 | 实测版本 | 路径 | 说明 |
|---|---|---|---|
| 仿真器（二选一） | Questa 2025.3 | `C:\altera_pro\26.1.1\questa_fse\win64\vsim.exe` | 全量 140/140 PASS（`sim/out/post_fix4_full140_20261018_011708`） |
| 仿真器（二选一） | ModelSim SE-64 2020.4 | `C:\modeltech64_2020.4\win64\vsim.exe` | 全量 140/140 PASS，与 Questa 逐 `test_id` 一致（`evidence/modelsim_se_140/`） |
| Python | 3.12.10 | 加入 PATH | 生成黄金向量 |
| OS / Shell | Windows + PowerShell | — | `run_regress.ps1` 自动找 `vsim`，或用 `-VsimPath` 指定 |

`-OutDir` 相对 `sim/`，例如 `out/my_run`，不要写成 `sim/out/...`。

## 2. 跑回归

在仓库根：

```powershell
.\sim\run_regress.ps1 -Tests T01,T13,T42
.\sim\run_regress.ps1
.\sim\run_regress.ps1 -VsimPath "C:\modeltech64_2020.4\win64\vsim.exe"
```

第一行是冒烟。第二行是 manifest 全量 140。ModelSim SE 实测墙钟约 20 分钟（`wall_s=1167.8`）。Questa 同集更早一次全量也是 140/140，墙钟随机器而变，不把 SE 的 20 分钟写成 Questa 的时间。

预期：140/140 PASS。冒烟 3 项通过不等于全量已在本机重跑。

## 3. 可选环境

- oss-cad-suite：`C:\Tools\oss-cad-suite`（Yosys 0.70 / SymbiYosys）。跑 formal 前先 `. C:\Tools\oss-cad-suite\environment.ps1`。有界 BMC 见 `formal/ENV_STATUS.md`。
- eLinx 3.0：综合。不是跑功能回归的前提。

## 4. 常见坑

- 中文乱码：`$env:PYTHONUTF8='1'`。
- formal 跑不起来：多半没 source oss-cad-suite。`.sby` 注释用 ASCII。
- 找不到 vsim：`-VsimPath` 指到 `vsim.exe`。
- 不要把 `sim/out/` 整目录当成交卷物。要留证时只复制 `regress.csv` 与 `run_metadata.json`。
