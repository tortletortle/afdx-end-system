架构决策状态 (D10–D13)

D10 · 发送起始错相

IMPLEMENTED / TOP-LEVEL VERIFIED

按 VL/BAG 错相提交，T05b 特定压力下已测。
未覆盖：全 BAG 档、STA、官方认证。

D11 · 块所有权与释放

IMPLEMENTED / VERIFIED

块池、端口读回、耗尽恢复、SAP handoff 已有局部证据。
未覆盖：完整 T08 全链路长期守恒。

D12 · 双网 RM 仲裁

IMPLEMENTED / VERIFIED

IC 后 RM，A/B 去重、SkewMax/seen。
未覆盖：多帧迟到历史、network babbling、形式化验证。

D13 · PMEM/主机仲裁

IMPLEMENTED / VERIFIED

RX 优先、pending/延迟 ACK、主机写读回。
未覆盖：无限时长公平性、完整混合事务。

证据边界与下一步

可直接用于项目 / 答辩

  • 赛方明确 GMII、自建激励/回环/检查器；
  • TX/RX 主数据路径与 50/50 回归快照；
  • IC/RM/SkewMax 论文与形式化建模参考；
  • GMII/RGMII/PHY/STA 接口资料。

尚不能宣称完成

  • 完整 ARINC 664/615A 官方认证；
  • 官方一致性测试套件 / golden vector；
  • 全表逐帧 T08/T22、10 万帧长时压力；
  • 当前顶层综合与 125 MHz STA。

下一步

  1. 冻结 SNMP/615A/RTC 项目子集；
  2. 完成完整 T08/T22 逐帧 scoreboard；
  3. 复核 RM 多帧迟到历史与 network babbling；
  4. 建立顶层综合 active revision 与 125 MHz STA。
