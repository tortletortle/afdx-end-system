## 1.（备用）仿真为什么是 125 MHz？做没做时序签核？

赛题要求综合后仿真，未要求时序签核；仿真按 GMII 速率 125 MHz，未做布局布线后时序收敛。

## 2. 为什么自研 MAC，没用 eLinx IP？

- 交付是 ES 协议行为 + 自建 TB；口是组委会确认的 **GMII A/B**。
- 自研 `mac_tx_if` / `mac_rx_if` 便于与 BAG/IC/RM 同一仿真闭环。
- eLinx 是综合/工程入口，不是必须绑其以太网 IP。

## 3. 128 TX / 4096 RX 怎么验证？口径是什么？

- **表/查找能力**：T12* 等（容量与查找，不是「4096 路同时收」）。
- **128 TX 同时活动吞吐**：T90 **P** — `t90_tx_a_mbps`/`t90_tx_b_mbps`=`679.188`，`t90_rx_dedup_mbps`，`t90_pass`。
- **4096 RX 覆盖**：T35p — `t35p_pass`（逐 VL 覆盖，非同时收）。
- **规模旁证**：T34p — `t34p_pass`；综合 `cells`/`altsyncram`。
- **适用边界**：本结论限于已跑规模/吞吐场；不含任意配置均 ≥100 Mbps，也不含 4096 路同时收。

## 4. 「2 ms」的起止点？

- **官方字面**单帧 GMII SFD→同帧 SFD ≤2 ms：单 ES 回环无网络段 → **I**（不宣称已 P）。
- **ES 贡献（本工程 P）**：T89 `t89_tx_commit2sfd_max_ns` / `t89_rx_sfd2host_max_ns` / `t89_es_total_max_ns`=`5976`（commit→TX SFD、RX SFD→host、二者之和）。
- 工程另列：T42 `t42_tx_commit_to_eof_max_us` / `t42_rx_sof_to_host_max_us`；T13/T13w worst。
- **适用边界：**不以「官方 2 ms 实测 0 ns」或「SFD→SFD 已 P」表述本作品结论。

## 5. 为什么在 1G GMII 上跑 100 Mbps AFDX？

- 接口用 1G GMII 字节节拍，便于与常见 MAC/FPGA 模型对齐。
- AFDX 侧用 **BAG + 份额** 约束聚合带宽（见 T05b/T05c、T27/`t27_pass`）。
- 「口是 1G、业务按配置整形」——接口速率 ≠ 已声明的 VL 预算。吞吐例：T42/`t42_tx_a_mbps`，T90 满配键。
