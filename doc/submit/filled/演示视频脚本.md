## 附：ffmpeg 转码 + ffprobe 核时（成片 ≤2:50）

假设粗剪导出为 `demo_raw.mp4`，输出 `demo_submit.mp4`（H.264 + AAC，常见平台友好）：

```powershell
# 1) 转码（若粗剪已超 2:50，先按结束时间裁到 170s）
ffmpeg -y -i demo_raw.mp4 -t 170 -c:v libx264 -pix_fmt yuv420p -preset medium -crf 20 -c:a aac -b:a 128k demo_submit.mp4

# 2) 核对时长（须 ≤170 秒 ≈ 2:50）
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 demo_submit.mp4

# 3) 可选：分辨率/编码摘要
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,avg_frame_rate -of default=nw=1 demo_submit.mp4
```

判定：`duration` 打印值 **≤ 170** 才上传；超过则改 `-t` 或重剪分镜。
