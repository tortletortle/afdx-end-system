## 2. 演示视频转码（ffmpeg）

前置：本机已装 `ffmpeg` / `ffprobe`（PATH 可调用）。

```powershell
# 输入：原始录像（可改路径/扩展名）
$In  = '.\raw_demo.mov'          # 或 .mp4 / .mkv
$Out = '.\doc\submit\演示视频.mp4'

# 输出：MP4 · H.264/AVC · AAC · 时长裁到 ≤3 分钟 · 体积目标 ≤300 MB
# -t 180 = 硬上限 180 s；CRF 23 可按体积再调（越大越小文件）
ffmpeg -y -i $In -t 180 `
  -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 23 -preset medium `
  -c:a aac -b:a 128k -movflags +faststart `
  $Out
```

若仍 >300 MB，提高 CRF（例如 26）或降分辨率：

```powershell
ffmpeg -y -i $In -t 180 `
  -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2" `
  -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 26 -preset medium `
  -c:a aac -b:a 96k -movflags +faststart `
  $Out
```

## 3. ffprobe 核对命令

```powershell
$Out = '.\doc\submit\演示视频.mp4'

# 时长（秒）、编码、分辨率、文件大小
ffprobe -v error -show_entries format=duration,size,format_name `
  -show_entries stream=codec_name,codec_type,width,height,profile `
  -of default=noprint_wrappers=1 $Out

# 一键断言（时长≤180、H.264、MP4、≤300MB）
python -c @"
from pathlib import Path
import json, subprocess, sys
p = Path(r'$Out')
assert p.is_file(), 'missing'
mb = p.stat().st_size / 1024 / 1024
probe = subprocess.check_output([
  'ffprobe','-v','quiet','-print_format','json','-show_format','-show_streams', str(p)
], text=True)
j = json.loads(probe)
dur = float(j['format']['duration'])
vcodecs = [s['codec_name'] for s in j['streams'] if s.get('codec_type')=='video']
print(f'size_MiB={mb:.2f} duration_s={dur:.1f} video={vcodecs} format={j[\"format\"].get(\"format_name\")}')
assert mb <= 300, 'size>300MB'
assert dur <= 180.5, 'duration>3min'
assert 'h264' in vcodecs, 'need H.264/AVC'
assert 'mp4' in (j['format'].get('format_name') or ''), 'need mp4'
print('VIDEO_CHECK PASS')
"@
```
