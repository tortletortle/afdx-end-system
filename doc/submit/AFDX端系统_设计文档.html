1. 赛题与范围

实现 AFDX（ARINC 664 Part 7）端系统（ES）五类功能：

  • 发送调度与流量整形
  • 接收过滤与完整性 / 冗余管理
  • 主机接口与存储
  • 管理面（SNMP / 615A / TFTP）
  • 时间同步（RTC / PPS）

协议子集以赛题与答疑为准；默认 GMII 公开端口（IF_MODE=2 指标场另述），仿真时钟对齐 GMII 线速拍。

不宣称完整认证、交换机、对端真 ES 闭环。

2. 总体架构

顶层模块 AFDX_top。数据流见 doc/figs/fig1_dataflow.mmd。

TX 链

port buf→ VL / BAG→ 组帧 / SN→ 双网复制→ MAC

RX 链

MAC / strip→ 查表 / 过滤→ IC→ RM→ 重组 / 交付

另有主机总线与管理 SAP、块池 / PMEM。

3. 接口

  • GMII：8-bit 数据 + valid；双网 A/B；ready 语义按赛方答疑（TX ready 可忽略场景有 TB 覆盖）。
  • 主机总线：host_cs/we/addr/wdata/rdata/ack/irq；配置表、PMEM、消息队列见 regs.yaml 生成附录。
  • PPS：pps_in / pps_out；RTC 微秒计数可读。

4. TX 通路

端口消息经 tx_port_buf / tx_message_store 进入调度；tx_vl_scheduler 按 BAG 与份额整形；tx_frame_builder 组以太网/IP/UDP/AFDX SN；tx_rm 双网复制；mac_tx_if 附加前导/FCS/IFG。

答辩一句：BAG 错相，避免多 VL 同相突发。

5. RX 通路

mac_rx / strip→ vl_lookup→ flt→ IC (SN)→ RM (SkewMax)→ 重组 / 解析→ port_buf

顺序固定（必须能背）：过滤 → IC → RM。不要说成 RM 在 IC 前面。

6. 存储与块所有权

块池与 PMEM 预算见图 2（figs/fig2_block_owner）。RX 块在过滤拒绝、IC 拒绝、RM 重复、交付完成等路径上释放；主机与 RX 写端口仲裁，避免同拍冲突。

7. 管理面

  • SNMP：snmp_lite（v1；community/长度策略见模块头注释）。
  • ARINC 615A / TFTP：加载/卸载状态机与数据报路径见图 3（figs/fig3_tftp_615a）。
  • RTC：PPS 驯服 FLL；漂移与扰动有专用 TB。

当前 RTL 支持 IP 分片重组与 615A 路径（覆盖范围以测试报告为准）；不以过期设计书「未实现」句为准。

8. 关键算法（答辩重点）

BAG

每 VL 令牌/年龄与错相偏移。

查表

可配置种子哈希，双表多路。

RM

窗口与 SkewMax；双网先后到达去重。

时延界

工程总时延与规范 BAG+抖动+技术时延分列；数字见测试报告。

9. 时钟复位与参数

系统时钟与 GMII 线速拍一致（仿真）。异步复位经 rst_sync。可配置：NUM_TX_VL / NUM_RX_VL、BAG、Lmax、份额、SkewMax、IC first-any 等，经主机表加载；init_sweep 清表。
