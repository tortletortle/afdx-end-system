## 2. 项目是什么

2026 全国大学生嵌入式芯片与系统设计竞赛 FPGA 赛道，中科亿海微**选题一 AFDX 端系统**。以 Verilog RTL、Questa/ModelSim 仿真、Python 黄金模型及 eLinx 交付为主线。

典型规格由现有设计/任务书描述为：128 TX VL、4096 RX VL、256 端口、32 KB PMEM、内部时钟目标 125 MHz。

- **TX**：主机配置与消息 → 缓存 → VL/BAG 调度 → 组帧、SN → 双网发送。
- **RX**：双网接收 → 缓冲/查表/过滤 → IC → RM → 端口或管理 SAP。
- **管理面**：SNMP、615A/TFTP 子集、RTC 与统计。
- **验证**：黄金模型、单元与顶层 TB、故障注入、回归 CSV；功能、时序、覆盖率、赛方交付分别取证。

`IF_MODE=0` 是 125 MHz 下 10 拍/字节的 100 Mbps 档；`IF_MODE=1` 是连续字节额外档。后者不能替代前者的评分指标。`competition_case/` 与 PMUX 材料属选题二，不并入本项目主线。
