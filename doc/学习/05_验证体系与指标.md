### 2.1 T93 单 VL 抖动 3080 ns 从哪来（答辩素材）

**一句话：** 来自封装接收侧 `afdx_app_rx` 轮询 MSG_CNT 的相位，只出现在第 0 帧；不是核心调度器，也不是 BAG 整形。

**依据：** 把 8 帧时延拆成「`tx_valid` 首字节→A 网 TX SFD」和「SFD→`rx_data` 首字节」两段（`t93_gmii_sfd.csv` + 诊断 TB 对 VL32 轮询时刻的打印）：

| 段 | 极差 | 说明 |
|---|---|---|
| tx→SFD | 15 周期（120 ns） | 调度器 / tick 门控的贡献，在这一级 |
| SFD→rx | 393 周期 | 差异全在第 0 帧 |

- 轮询一圈 = 126 个 VL × 5 周期 = **630 周期 ≈ 5.04 µs**（2524 次 VL32 访问里最常见的间隔），这是该抖动的上界量级；TX 提交占总线时一圈会拉长到 661–1734 周期。
- 第 0 帧：VL32 在 SFD 后 +87 周期被轮询，消息尚不可见（读到 0），要等下一圈到 +717 才读到 1。第 1–7 帧在 +324 到 +339 轮询，已可见。多出的约 385 周期 = 3080 ns。
- 为什么只有第 0 帧：它在 `cfg_done` 后 1 个周期提交，轮询刚从 VL0 起扫；之后每帧轮询相位与提交结束时刻锁定。这是推断，没有逐周期仲裁轨迹。
- 没改判据，没改 RTL。消除需要把轮询改成事件驱动，是另一项改动。
- 详见 `doc/T93_抖动来源与BAG判据_20261029.md`。等级：来源分解 **I**（诊断）。

**BAG 判据两处互相引用：** T93 新增「按 VL 的 TX SFD 间隔 min ≥ BAG（125000 周期）」，实测 min=132133 周期，**P**（该场景）。但 TB 注入间隔约 132144 周期 > BAG，只说明封装没有早于 BAG 发帧；BAG **整形**的证据仍是核心测试 T04 / T05c / T27 / T90，封装没改调度器。

## 4. 测出过的真 bug（五则故事）

出处：测试报告 §8。

### D1 · chipsim 漏接 `rx_error`

- **现象：** 缩配顶层 `rx_error*` 悬空 → GMII RX 遇 X 进 DROP，回环 `MSG_CNT=0`。
- **根因：** `AFDX_top_chipsim.v` 未引出/接到 `u_es` 的 `rx_error` / `rx_error_b`。
- **修法：** 补端口并接 0（或驱动）；新增 `tb_chipsim_smoke.v`。
- **回归：** **T88a**（修前 FAIL / 修后 PASS）。

### D5 · T89 PSN 污染

- **现象：** 多阶段指标场后接官方 e2e，IC **PSN 被前段污染** / 共享 VL_RX 串扰。
- **根因：** 连续激励未 hard re-init；配置曾共享 RX 索引。
- **修法：** TB 独立 VL_RX；jit32 后 `wait_init` 再跑 e2e。
- **回归：** **T89**（checks + Python 复算）。

### D6 · SAP ready 门控

- **现象：** SAP 忙时仍对同一描述符重复接收。
- **根因：** 入站 valid 未与 `sap_engine_ready` 联合门控。
- **修法：** `AFDX_top`：`prs_to_sap && sap_engine_ready`。
- **回归：** **T15 / T15g**（并入现行全量）。

### D7 · TFTP 主机地址位宽

- **现象：** 地址映射 warning / 宽度不一致风险。
- **根因：** 16 位基址减法后未显式取窗内 13 位。
- **修法：** `host_addr - 16'hCC20` 再取 `[12:0]`；穷举有效窗。
- **回归：** 地址穷举脚本 + 相关全量项。

### D8 · 管理面上线缺陷（写 T24 时暴露）

- **现象：** 管理面能写 PMEM，调度却拿到 `blk=0` / `len=X` 坏描述符 → builder 卡死；响应 FSM 曾抢走观测窗字节致 T15/T16 FAIL。
- **根因：** 误用主机 `MSG_WR` 的 `port_type`/`port_depth`；响应上线未加开关。
- **修法：** 管理面固定 type=2、深度取真实 SAP；响应经 PMEM→`msg_commit`，**CTL[9]** 开关。
- **回归：** 当时定向 **T15/T16**；现行 SNMP/管理相关 T 计入 145。
