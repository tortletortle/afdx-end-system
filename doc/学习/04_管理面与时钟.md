## 1. `snmp_lite`

**1. 解决什么问题**  
片内如何用硬件完成 SNMP 读改，而不挂软核协议栈？

**2. 原理**  
只做 **SNMPv1**：version≠0 丢弃；支持 GET / GETNEXT / SET；community 约定 `public`，错 community **静默丢弃**（无响应）。企业 MIB 为标量 / STATS / 部分 VL 索引子集。  
例：错 community 的 SET → 无应答 PDU（T88 步 5）；对的 GET → 经管理 SAP 回响应。

**3. 代码位置**  
`rtl/mgmt/snmp_lite.v`：`module` **L64**；FSM `P_*`/`E_*` **L140–160**；主时序 `always @(posedge clk)` **L507+**。

**4. 对应测试**  
T15*（SNMP 族）；T88 步 5；`t88_steps_ok`=`8`，`t88_pass`。等级 **P（子集）**。

**5. 评委追问**  
- 版本？仅 v1。证据：设计文档 §1.3 / §8.1；`snmp_lite.v`。  
- 错 community？静默丢。证据：T88 步 5。  
- 完整 MIB / v3？**未实现** → **F**。

**实现到 / 没实现**  
做到：v1 GET/GETNEXT/SET + community。没做：v2c/v3、TRAP、GETBULK、认证级 MIB、对端真 NMS 闭环。

## 2. `a615a_tftp` 及 615A 子集

**1. 解决什么问题**  
如何在片内用 TFTP 语义做配置/镜像的加载与卸载，并披露 615A 相关子集边界？

**2. 原理**  
`a615a_tftp`：WRQ 加载 / RRQ 卸载；块号推进；ACK；超时重发。  
- 加载：白名单文件名 + `octet` → ACK 开会话；DATA 按块写入（默认 512 B）；重复块只补 ACK；末块 &lt;512 B → `loaded_ok`。  
- 卸载：有镜像则按块回 DATA，对端 ACK 推进。  
- 超时：`TIMEOUT_US` 无后续则重发；`retry_cnt`&gt;`RETRY_MAX` 本地 ERROR 终止。  
例：520 B 载荷 ≈ 2 块（512+8）；T88 步 6 演示 WRQ+DATA 加载与 RRQ 读回。

**3. 代码位置**  
`rtl/mgmt/a615a_tftp.v`：**L70**；`K_ACK`/`K_ERR`/`K_DATA` **L125**；`sess`/`blk` **L131+**；主 `always` **L331**。  
相关：`a615a_fetch_engine`（主动取件）；`a615a_lur_*`（LUR 控制/编排**子集**）。

**4. 对应测试**  
T88 步 6；T16u；T43；`t88_pass`。等级 **P（子集）**。

**5. 评委追问**  
- 615A/665 硬要求吗？**非硬要求**（设计文档 §1.3）。  
- 交了什么？TFTP 加/卸载子集 + 有限 fetch/LUR。证据：T88/T16u/T43。  
- 对端真装载机？**未闭环** → **F**。

**答疑口径**  
答疑：615A 数据加载及 665 解析非硬要求。本仓披露现测 TFTP 子集与边界；不宣称完整 615A/665。

## 3. `rtc_sync`

**1. 解决什么问题**  
如何用外部 PPS 驯服片内 RTC，并给出可读微秒时间与失步指示？

**2. 原理**  
`rtc_time_us = rtc_free_us + offset + freq_bias`（μs）。PPS 上升沿估计误差；可选 FLL（`FREQ_LOCK_EN`）。超时可置 `sync_loss`；连续合锁 → `locked`。  
例：T16a 多案 FLL 最大绝对误差 `t16a_fll_max_abs_err_us`=**1** μs；T88 步 7 演示失步清除与时间前进（精度仍归 T16a）。

**3. 代码位置**  
`rtl/mgmt/rtc_sync.v`：**L23**；`rtc_time_us` **L105**；`pps_rise`/`err` **L107–114**；主 `always` **L145**；`sync_loss`/`locked`。

**4. 对应测试**  
T16a：`t16a_pass`；`t16a_fll_max_abs_err_us`=`1`。T88 步 7 为演示旁证。等级 **P（该剧本）**。

**5. 评委追问**  
- 网络授时？顶层仍接 **0**（设计文档适用边界）→ 不宣称已闭环。  
- 仿真 125 MHz？是 GMII/TB **拍频参数**，不是板级时序签核。  
- 亚微秒？头注释不宣称 → **F**。

**实现到 / 没实现**  
做到：PPS/FLL 驯服、`rtc_time_us`、失步/锁定。没做：网络授时口闭环、CDC/板级时序结论、亚微秒宣称。
