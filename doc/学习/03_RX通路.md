# 03 RX 通路

> 面向：队员答辩学习。读完能按模块讲清「收什么、谁去重、4096 怎么固定拍查」。  
> 链：`gmii_rx_strip` → `mac_rx_if` → `rx_vl_lookup` → `rx_flt` → `rx_ic` → `rx_rm` →（可选 `rx_reassembly`）→ `rx_ip_udp_parse` → 端口。  
> 判断序固定：**过滤 → IC → RM**。数字仅用下列 T / metrics；**P** 只覆盖对应 TB。

**口径：勿用第1节禁用宣称词；详见 `07_答辩问答与口径.md` §D。
**可说：** 4096 条 VL 查表/遍历覆盖；A/B 同帧只交付一次。

## 重点故事（先背这两句）

### A) A/B 同帧只交付一次

双网同 VL、同 SN。`rx_rm`：先到的 `out_fwd` 交付；Skew 窗内后到同 SN → dup 丢弃。白话：先到留下，后到扔掉。  
证据 T10 console：`fwd=56 dup=46 skew=3` → metrics `t10_fwd`/`t10_dup`/`t10_skew`。旁证 `t90_rx_dedup_mbps`=**673.304**（去重后计一次）。

### B) 4096 VL 固定拍数查找

非线性扫表。双表 4-way + 五级流水，**固定拍数**出 hit/idx。证据：设计文档 T12c `lookups=100000`；`t35p_pass`（逐 VL 覆盖，**≠** 同时收）。

## 1. `gmii_rx_strip`

**1 问题**  
PHY 带前导，后面模块要干净帧体时谁剥？

**2 原理 + 数字例**  
剥 7×`0x55`+`0xD5`。FSM：`PRE` 数前导 → `BODY` 放行 → 畸形进 `DROP` 直到 `RX_DV` 掉。例：第 8 字节非 `D5` → DROP。

**3 代码位置**  
`rtl/rx/gmii_rx_strip.v` L7；FSM PRE/BODY/DROP L18–31。

**4 测试 + metrics**  
随 T08* 入口。通路 **P**；单独 strip 标 **I**。

**5 评委 3 问**  
- 为何无 ready？连续 `RX_DV`，故意无反压。  
- BODY 遇 `RX_ER`？下传；坏 CRC 侧不产 desc。  
- DROP 何时回 PRE？`!rx_valid`。

## 2. `mac_rx_if`

**1 问题**  
谁拦住坏帧，不让其进 VL 查表？

**2 原理 + 数字例**  
流式 FCS/IP/UDP：整帧过且末笔 PMEM 写提交后才 `desc_vld`；坏帧可暂写块再释放，**无 desc**。例：CRC 错 → `blk_release`。旁证 `t89_rx_sfd2host_max_ns`=**2592**（工程 RX SFD→host，**≠** 官方端到端）。

**3 代码位置**  
`rtl/rx/mac_rx_if.v` L11；收帧 `always` L170+。

**4 测试 + metrics**  
T08a 等。**P**（该 TB）。

**5 评委 3 问**  
- IF_MODE 0/1？0=包络；1=逐拍 DV。  
- 为何不先交后撤？坏帧无 desc。  
- A/B？`NET_ID` 进元数据。

## 3. `rx_vl_lookup`（必讲透）

**1 问题**  
4096 条 VL 如何固定拍数查完、而不是线性扫？

**2 原理 + 数字例**  
- 参数：`NUM_RX_VL=4096`，`HASH_BUCKETS=2048`。  
- 存储：`table0way0/1`、`table1way0/1`（L53–56）→ 双表×2-way=**4-way**。  
- 哈希（与 `sw/golden/hash_seed.py` 位一致）：  
  - `HASH_ADD`：`sum = vlid + seed + 0x9E37` / `0x1F5B`（L159–162）  
  - `mixed = sum ^ (sum>>7)`（L65–66）  
  - `HASH_MUL`：`product = mixed * 0x9E37` / `0x45D9`（L164–167）  
  - `hash = product ^ (product>>9)` → 桶号（L67–70）  
- **五级流水**（接收入口后五个边沿可握手；L42–43、L136–187）：  

| 级 | 做什么 |
|---|---|
| HASH_ADD | 两路加常数得 sum |
| HASH_MUL | xor-shift 后乘常数得桶址 |
| RAM_READ | 同步读四路字入 `q00..q11` |
| COMPARE | 4-way `valid_match`，出 `out_hit`/`out_vl` |
| OUTPUT | 等 `out_ready` 回 IDLE |

IDLE 仅锁存 VLID/seed/desc，不算流水级。  
- **离线摆放**：`cfg_mode` 且 RX 关时写表；**无运行期探测/驱逐**。失败镜像不得开 RX。  
- 例：T12c `lookups=100000`；`t35p_pass`=4096 RX **覆盖**旁证。

**3 代码位置**  
`rtl/rx/rx_vl_lookup.v` L11；表 L53–56；hash L65–70；ADD/MUL L159–167；流水 L42–43、L136–187。

**4 测试 + metrics**  
T12c/r/s/h/f；T35p/T08f。**P**（查表）；「同时收满 4096 VL」**F**。

**5 评委 3 问**  
- 为何固定拍？无 miss 重试、无驱逐。  
- 4-way？`m00\|\|m01\|\|m10\|\|m11`，优先 m00→m11。  
- 表何时写？离线 CFG；运行只读。

## 4. `rx_flt`

**1 问题**  
命中哈希后还滤什么？

**2 原理 + 数字例**  
一拍判决（L38–49）：`F_PASS` / `F_UNCONF` / `F_NET` / `F_LMAX` / `F_VLID`。例：`in_hit=0` → UNCONF，父层放块。

**3 代码位置**  
`rtl/rx/rx_flt.v` L16；原因码 L38–49。

**4 测试 + metrics**  
T08*。**P**（该 TB）；全错误笛卡尔 **F**。

**5 评委 3 问**  
- 与 lookup？lookup 给 idx；flt 对 CFG。  
- `net_mode=00`？当仅 A。  
- 拒谁放块？父层 `free_pipe`。

## 5. `rx_ic`

**1 问题**  
SN 怎样判可接受？

**2 原理 + 数字例**  
每 VL×网一份 PSN。`exp1`/`exp2`（L65–66）：下一期望 / 丢一帧仍可接受。判决 L76–95：SN=0 复位接受；PSN=0 时仅 SN=1 或 `first_any`；否则仅 `exp1`/`exp2`。例：PSN=5，SN=6→OK；SN=7→LOST_ONE；SN=9→拒。

**3 代码位置**  
`rtl/rx/rx_ic.v` L7；FSM L36；exp L65–66；accept L76–95。

**4 测试 + metrics**  
T09：`t09_accept`=**1759**，`t09_reject`=**4248**。**P**。

**5 评委 3 问**  
- 拒改 PSN？不改。  
- 与 RM？IC 在前。  
- `IC_EN=0`？旁路进 RM。

## 6. `rx_rm`

**1 问题**  
A/B 如何只交付一次？

**2 原理 + 数字例**  
`skew = 4 << exp`（μs，L133）。`same_sn`+`in_win`（L99–115）：窗内同 SN→dup；超窗→skew 并可 fwd。白话同故事 A。例：T10 `fwd=56 dup=46 skew=3`。

**3 代码位置**  
`rtl/rx/rx_rm.v` L39；skew L133；same_sn/in_win L99–115；`out_fwd`/`out_skew`。

**4 测试 + metrics**  
T10/T10g；`t90_rx_dedup_mbps`=**673.304**。**P**。

**5 评委 3 问**  
- SkewMax？`4<<exp` 微秒。  
- 先到后到？先到 fwd，窗内后到 dup。  
- 能推 babbling 全空间？**不能**。

## 7. `rx_block_pool`

**1 问题**  
块如何不双释放、不泄漏？

**2 原理 + 数字例**  
块 6..11 专属 RX，12..15 可借；复位 `free_map=16'hFFC0`（L16）。`free_pipe`（L11–12、L107）是流水释放口。  
**所有权不变量：每块唯一持有者。** 无 ownership 信号名——靠顶层同一 `free_pipe` **按拍互斥**（`rtl/top/AFDX_top.v` ~L1752/L1786）：**RM 输出 > IC 拒绝 > FLT 拒绝 > drain**。

**3 代码位置**  
`rtl/rx/rx_block_pool.v` L4；`free_map` L16；`free_pipe` L11–12、L107；复位 `16'hFFC0`；顶层 ~L1752/L1786。

**4 测试 + metrics**  
随 RX TB。**I**（无独立 ownership TB）/ 通路 **P**。

**5 评委 3 问**  
- 单 free_pipe？防同拍覆盖丢释放。  
- 解析 drop？经 `rx_port_buf`，不占 pipe。  
- FFC0？高 10 位空闲（块 6..15）。

## 8. `rx_ip_udp_parse`

**1 问题**  
RM 后如何落到端口？

**2 原理 + 数字例**  
不再回读 PMEM 做 IP/UDP 校验（已在 mac）。按 `RX_VL_CFG.port_base` 匹配：valid、dir=RX、type∈{采样,队列}、UDP dport。例：dport 不符→drop，块由 port_buf 归还。

**3 代码位置**  
`rtl/rx/rx_ip_udp_parse.v` L20。

**4 测试 + metrics**  
T22 等。**P**（该 TB）。

**5 评委 3 问**  
- 与 mac？mac 帧正确性；本级端口语义。  
- SAP？`sap_enable` 交管理面。  
- drop 谁放块？`rx_port_buf`，不占 `free_pipe`。

## 9. `rx_reassembly`

**1 问题**  
分片何时拼回整消息？

**2 原理 + 数字例**  
位图重组（8 B/位）；重叠拒；MF=0 后 `[0,end)` 全 1 才交付。`en=0` 或非分片透传。参数化可选 **`RX_REASM_CHAIN`**（顶层 `RX_REASM_CHAIN_BLOCKS`，链版 `rx_reassembly_chain`）。

**3 代码位置**  
`rtl/rx/rx_reassembly.v` L22；链使能见 `AFDX_top` 参数。

**4 测试 + metrics**  
分片 TB（若启用）。未开链以透传为主；勿夸全部分片认证。

**5 评委 3 问**  
- 链上何处？RM forward 后、parse 前。  
- TIMEOUT？工程可选；0 禁用。  
- 默认总开链？看顶层 elaborat 配置。

## 当日自检（5 题）

1. 默写 RX 顺序；过滤/IC/RM 谁先？  
2. 白话讲 A/B 只交付一次；写出 T10 三数与 metrics key。  
3. 画出五级流水；HASH_ADD 公式；为何 T35p 绿了仍不能说「同时收满 4096 VL」？  
4. `free_pipe` 四档优先级？何谓「每块唯一持有者」？  
5. 写出：`t09_accept/reject`、`t90_rx_dedup_mbps`、`t89_rx_sfd2host_max_ns`、T12c `lookups`。

### 答案

1. `strip→mac→lookup→flt→ic→rm→(reasm)→parse→port`；**flt→ic→rm**。  
2. 先到 fwd，窗内同 SN 后到 dup；`56/46/3` → `t10_fwd/dup/skew`。  
3. ADD→MUL→RAM→COMPARE→OUTPUT；`vlid+seed+0x9E37/0x1F5B`；T12c/T35p 是查表/覆盖，非同时收满。  
4. RM 出 > IC 拒 > FLT 拒 > drain；互斥释放保证一块一时一个主人。  
5. 1759/4248；673.304；2592；100000。
