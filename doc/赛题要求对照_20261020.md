## 3. 全局口径边界（随表必附，去掉即为 F）

- **子集 ≠ 完整协议合规**：A664P7 / 615A / SNMPv3 全栈一致性仍 OPEN，待赛方版次与官方套件。
- **时延**是 ES 芯片内 + TB 回灌，**非真网络端到端**（无对端交换机/真 ES 闭环）。
- **128 / 4096 VL** 为 net_model / 遍历覆盖口径，**非物理端口同时满载并发**。
- **RTC/FLL** ≤1μs 为仿真场景值，T39 自标 **no CDC/board claim**，非板级签核精度。
- **形式验证**为**有界** BMC（BMC40），不等于无界证明，不替代仿真 T。
