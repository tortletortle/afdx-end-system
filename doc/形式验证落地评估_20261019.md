## 2. 本项目可证不变式候选（按落地优先级）

OPT-10 原文目标：块池守恒、RM 不重复、IC 拒绝不写 RM（BMC depth 约 30~50）。本评估补上调度 BAG，并按难度排序。

### 2.1 BAG 间隔（`tx_vl_scheduler`）— 准备中

| 维 | 内容 |
|---|---|
| 命题 | 同一 VL 两次 `frame_start` 之间，`cycle_count` 增量 ≥ `bag_arr[vl]` |
| 准备件 | `formal/tx_vl_scheduler_bag.sv` + `formal/bag.sby`（**未跑**） |
| 难度 | **中**：阵列 `next_tx`/`bag_arr`×128、ifq、FSM/扫描；全配 BMC 易爆炸 |
| 深度估计 | 缩配（如 `NUM_TX_VL=4`、小 BAG）BMC **40~80**；全配 128 需抽象/切片，否则不实用 |
| k-induction | 有助手不变量（inflight、ifq 守恒）时 **k=5~15** 可试；无助手则难收敛 |
| 窗口 | **等时序刀定稿**（减 lane / `group_idx` / 流水拍）后再跑 |
| 非目标 | ≠ L158 抖动合规；≠ 端到端 ≤2 ms；≠ WCTT |

### 2.2 RM 不重复（`rx_rm`）— OPT-10 / OPT-1

| 维 | 内容 |
|---|---|
| 命题 | 同一 VL、SkewMax 窗口内同一 SN **至多 forward 一次**；`SN==0` resync |
| 难度 | **中高**：4096 VL × 41 bit 表；需单 VL 切片或符号化 VLID |
| 深度估计 | 单 VL BMC **30~60**（OPT-10 口径）；全表不现实 |
| 前置 | OPT-1 位图已部分落地（代码可见）；越窗策略/SkewMax 检查仍缺则性质要收窄 |
| Windows | 单 VL 切片预期可跑；全表勿开 |
| **2026-10-19 续作** | VL0 切片、主表项 ghost、当前帧 skew：`sby -f rm.sby` **bmc20/bmc40 PASS**（boolector；`formal/rm_bmc20`、`rm_bmc40`）。性质已按 DUT 收窄（behind hist 不入 ghost）。**有界局部 P 候选**；不证 late_dup 全路径、≠ T10 替代。FAIL 史见 `formal/rm_bmc20_FAIL_NOTE.md` |

### 2.3 block_pool 守恒（`rx_block_pool` 等）

| 维 | 内容 |
|---|---|
| 命题 | 已分配块不在空闲位图；分配数+空闲数 ≡ 池容量；对空闲块 `free` 安全 |
| 难度 | **低~中**：状态机相对局部（OPT-10 首选） |
| 深度估计 | BMC **20~40**；k-induction **k=3~8** 较有希望 |
| 注意 | 顶层多源 `free_pipe` 仲裁时，性质应绑池模块端口，勿一口吞顶层 |
| **2026-10-19 续作** | 已对 **子性质** P1/P2/P3（TX 位不漏、`blk>=6`、A/B 互异）跑 BMC depth **40** → **PASS**（`formal/pool.sby`，boolector）。**仍是有界 I/局部 P 候选**；未证「空闲+在持≡10」、未证 CHAIN、未证顶层仲裁。详见 `formal/ENV_STATUS.md` |

### 2.4 IC 拒绝不写 RM（`rx_ic` → `rx_rm`）

| 维 | 内容 |
|---|---|
| 命题 | IC 拒绝的帧不产生对 RM 的写/forward；与 T10 污染检查同向 |
| 难度 | **中**：跨两模块握手；适合「接口契约」式断言 |
| 深度估计 | BMC **30~50**；需 assume 合法描述符流入 |
| 产出 | 补仿真记分板；**不**替代 T08e/T10 |

## 4. 方法边界（L136 / 尺子）

1. **FPV 补仿真，不替仿真**：Seligman 口径是小模块断言式 FPV；本仓仍以 Questa manifest 为 T 层主证据。  
2. **有界 ≠ 无界**：BMC depth N 只排除深度 ≤N 的反例；写报告须带 depth / 引擎 / 源版本哈希。  
3. **有证明仍是 I→P 的门槛**：对**最终** RTL 跑通且 assume 可审，方可把该条升到 P；准备件与调研停在 **I**。  
4. **覆盖率**：历史 67.82% 是仿真覆盖；formal PASS **不得**改写成「覆盖率 95%」。  
5. **时序**：formal 与 Fit/STA 无关；不得用 sby PASS 宣称 125 MHz。
