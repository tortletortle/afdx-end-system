## 0. 总判

你把「赛题不要求上板」理解成「可以不把 eLinx 综合后仿真当成硬门槛」，这是**口径偷换**。  
赛方要的是基于 FPGA 工具链的仿真与综合后仿真；不上板只免去板测，**不免** eLinx 调起仿真。  
你在笔记里其实已经写过正确边界（`比赛不要求实际上板`、`旁证禁止升格`、`工具链要在调研期跑通最小路径`），但**行为上仍按逃避路径走**——知道规矩却不执行，比不知道更糟。

面积线上，你用 FN512 换 LE，却不先跑 T49/T58；用「削减功能 → 降低测试标准」当退路——这是**用销毁验收尺子换心理安慰**。顾问与硬约束多次否决后，你仍反复试探。这不是「冲一把」，是**拒绝接受已冻结的交卷边界**。

## 1. 错误清单（按责任重量）

### E1：用「不上板」逃避 eLinx 综合后仿真（核心责任）

- **时间 / 证据**：长期；灰按钮落锤 `out/elinx_post_synth_sim_IF_20261031.md`；尺子 H6/H7；笔记 `afdx_notes_pkg/concepts/比赛不要求实际上板.md`、经验 E16  
- **现象**：优先堆 RTL/Questa/ModelSim/命令行 VO 门级；把「eLinx 调起 ModelSim 的综合后仿真」拖到 10-31 才认真做，按钮灰了就标 I/F 停  
- **影响**：交卷口径最硬的一条长期 I/F；旁证再绿也不能写成 C139.4 PASS；视频/答辩必须拆句，评委一问就露怯  
- **技术根因**：工具链入口未在调研期验证；Post-synthesis 工程与 Behavioral/Post-Impl 菜单能力未读透  
- **责任归属**：**你的选择**。不是厂商单独害你——厂商难用是已知风险；你主动把风险押后，理由是「又不上板」  
- **为何没早发现**：把「能综合出 .vqm」和「能从 eLinx 点仿真」当成一件事；有 T88b GUI 行为旁证就自我满足  
- **改则**：调研期必须跑通 **eLinx→ModelSim 最小一条**（哪怕空 TB）；不通则 OPEN/I/F 写进尺子，禁止用旁证顶替  
- **状态**：未修复（I/F）；无法在交卷前保证挽回  

### E2：旁证升格风险（H7）——纪律写了，仍反复想用旁证顶门

- **证据**：`doc/硬约束清单.md` H7；经验 E4；尺子明文；会话中多次讨论旁证能否顶 eLinx 调起仿真  
- **现象**：RTL 150、命令行 VO 门级 T88b、eLinx GUI 行为 T88b 被反复拿来问「算不算综合后仿真」  
- **影响**：若文档/答辩说成「eLinx 综合后仿真已过」，即违反自订 H7，属于口径事故；**本稿不声称对外材料已经写错那一句**——风险在决策习惯，不自动等于已提交造假  
- **责任归属**：尺子是你方定的；反复试探混用是**你的决策习惯**  
- **改则**：对外每一句仿真结论必须带路径标签；禁止「等价于」  
- **状态**：纪律已写；须通读已交 PDF 确认无升格句  

### E3：FN512 改接口不先验 TB（面积刀致 T49/T58）

- **时间 / 证据**：`out/ab_area_20261102/step2f_fn512_NOTE.md`；失败日志 `logs_2H_stop_*/T49_console.txt`、`tb_t58_lur_orch.log`；vopt 位宽警告  
- **现象**：filename 2048→512；TB 仍按 `[2047-:8]` 打包；DUT 吃到 0；面积冻结后回归才爆「新增 FAIL」  
- **影响**：隔离树面积达标却**不能合入**；浪费整段回归与截止窗口；差点把「面积成功」说成可交  
- **技术根因**：改端口契约却不跑契约测试；把「综合面积」当成「功能仍过」  
- **责任归属**：压资源节奏由你推；**刀后不跑单元测试就宣称冻结**是你的流程错误  
- **为何没早发现**：GUI 面积数字好看就停刀；把回归排在「面积 OK 之后」而不是「每刀必跑契约 TB」  
- **改则**：凡改对外位宽/包序，**同提交**必须跑直接消费者 TB（此处 T49/T58/T57）；不过禁止进面积冻结  
- **状态**：隔离树已做端口适配，T49/T58 已 PASS；全量回归当时仍在跑；主树仍未合入  

### E4：混淆 LE 与 CLB，还要「再砍一刀」

- **证据**：2H 结果 LE 108486/136000，CLB 13545/13600；用户原话「LE 不够稳」

- **影响**：盲砍只会制造新 FAIL 或再次超 CLB；占用截止前时间  
- **责任归属**：数字表已写在 PROGRESS/RESULT；**没读自己的停条件表**  
- **改则**：开口要砍之前，先念停条件表上的**紧约束项**  
- **状态**：顾问已否；未再砍  

### E5：提议删测试 / 降标准换「能交的仿真」

- **证据**：对话原话「测试没有通过就把对应的测试删掉」「削减功能换降低测试标准」
