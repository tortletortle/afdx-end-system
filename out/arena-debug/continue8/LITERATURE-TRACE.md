# Continue8 — 文献到设计与验证的可追溯映射

## 使用规则

- 下表中的“文献启发”只能支持职责划分、接口原则或测试方向；不能替代本项目的 RTL、Questa 回归、Quartus map/fit 或 TimeQuest 证据。
- `A` 级可复核资料的具体表述仍应回到原文和总体设计书确认；未重读全文的项目不扩展为新的协议断言。
- D10/D11/D12 是本项目既有工程决策；Continue8 不推翻它们，只规定 TX 时序重构必须保持的约束。

## 既有工程决策的保持条件

| 决策 | 当前工程含义 | Continue8 的保持要求 | 验证 |
|---|---|---|---|
| D10：发送起始错相 | VL/BAG 的启动错相和帧首调度 | event FIFO 不能把内部拥塞隐藏成提前发帧或错误的 BAG 计时 | T04、T05b/T05bg、T13 |
| D11：级联释放/块所有权 | RX block pool 的释放路径与块守恒 | TX 重构采用同样的唯一 owner 原则，但不改 D11 RX 释放实现 | T21、T22、T23、free-map 不变量 |
| D12：时间戳公平仲裁 | A/B 描述符按物理到达时间避免 RM skew 误判 | TX 改动不得改变 A/B 帧内容、SN 或影响 RX 到达时间戳定义；RX 后续重构需保留 TFA | T10、T22 及 D12 专项断言 |

## 可审计的论断边界

| 论断 | 分类 | 当前状态 |
|---|---|---|
| `s1_vld → s1_desc[*]` 是 post-map 最差路径，约 21.292 ns | 已验证工程事实 | 有 Continue7 STA 报告 |
| R/X/W 流水能缩短该路径 | 设计假设/推荐 | 尚待 RTL、回归和 STA 验证 |
| `desc/qst` 能映射到器件 BRAM | 待验证工程项 | 取决于最终端口协议与综合报告 |
| 文献支持端系统分层、队列/块所有权、BAG 与测试原则 | 文献依据 | 不等同于本工程通过 |
| 系统达到 125 MHz 或板级签核 | 不可声称 | 缺 IO 约束及 post-fit 证据 |
